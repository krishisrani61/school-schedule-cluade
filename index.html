From blank page to school year

  1. Define rotation labels and periods in School & periods. Start with any labels you need.
  2. Add a class, enter its details, and select meetings in the grid. Shorthand such as 1AD, 2BCF works with single-character rotation labels and numeric period labels. For other labels, use the grid.
  3. Set the calendar range and meeting weekdays. Mark breaks and override dates as needed.
  4. Preview events, then download an ICS file to import into your calendar.
  5. Save JSON to move the complete workspace between devices. Opening JSON replaces the current workspace after confirmation.

All work stays in your browser; no account, internet, or external scripts needed. Browser storage is a convenience, so keep a JSON backup. Different copies hosted on the same origin share the saved workspace. Changes here do not update an already imported calendar; import into a dedicated calendar that you can replace to avoid duplicates.

One bell schedule applies across the export range. To export separate timing regimes, change the bell times and export each date range separately. Changing class assignments likewise affects the whole selected range; historical versions can be kept as separate JSON files.
